项目背景与降本增效指标

律政题材影视在传统实拍中面临严苛痛点：高规格法庭场景搭建周期漫长且租赁费用昂贵，资深律师演员档期受限，群演（陪审团、旁听席）跨镜头走位繁复。

受腾讯短剧创新实验室委托，刘帅团队以纯 AIGC 全流程重塑律政微短剧第一季先导试播集。借助自研的“法庭空间几何 LoRA”与“主角五官锁定工作流”，在零实拍场地、零真人摄制的前提下，以影视工业级成片标准完成了 48 个多景别镜头的端到端交付。

创意策划与叙事架构

gavel
01 // CORE PREMISE

算法伪证与深渊审判

在一桩涉及万亿级 AI 智控公司的内幕操纵公诉案中，辩护律师林琛（Lin Chen）在最终质证环节，发现公诉方出示的致命核心视频证据本身系由深度自监督算法伪造。法庭从法律博弈演变为算法欺骗与伦理存亡的生死攻防。

theater_comedy
02 // AESTHETIC REFERENCE

新黑色电影 (Neo-Noir) 律政美学

汲取大卫·芬奇（David Fincher）《社交网络》与丹尼斯·维伦纽瓦的克制冷调。画面以去饱和冷灰青（Cool Cyan）与暗金阴影构筑压抑基底。剔除冗余修饰，强调极简、对称与压迫感极强的法庭几何纵深。

spatial_audio
03 // ACOUSTIC DRAMA

低频心率与空旷法庭声场

声音设计上刻意放大了法庭法槌敲击的回声、皮鞋敲击大理石地面、急促沉闷的西装摩擦音，配合 40Hz 恒定超低频合成器嗡鸣，在静默与声浪爆发间引发观众的生理级压迫感。

// SECTION 07

AI 生产管线与动态控制节点

STAGE 01 SCRIPT & PROMPTS

剧本节拍与Prompt工程

运用 Claude 3.5 Sonnet 解析经典悬疑剧本三幕架构，生成精准包含摄影焦段、布光角度、情绪强度的工业级分镜中英文 Prompt 矩阵。

ENGINE: Claude 3.5 Sonnet + Custom Python Parser
STAGE 02 KEYFRAME & LORA

高精度关键帧与LoRA锁定

在 ComfyUI 内接入自训练的 Kohya-ss Flux LoRA 模型，通过 IP-Adapter FaceID 与 ControlNet OpenPose 实现多机位下主角微表情与服饰完全锁定。

ENGINE: Flux.1 Dev + Kohya-ss LoRA + ComfyUI
STAGE 03 DYNAMIC SIMULATION

镜头轨迹与动态刷控制

将 4K 关键帧送入 Runway Gen-3 Alpha 与 Kling 1.5。采用 Motion Brush 精细圈定法庭窗外雨丝动态、人物领带飘动与眼睑微颤，杜绝画面形变崩坏。

ENGINE: Runway Gen-3 Alpha + Kling 1.5 Camera Path
STAGE 04 LATENT 4K UPSCALE

超分辨率与时序去闪烁

应用 Topaz Video AI 与 ComfyUI 潜空间重投影算法消除帧间闪烁（Deflickering），进行原生 4K UHD 60FPS 胶片颗粒注入，还原电影级胶片质感。

ENGINE: Topaz Video AI + SeedVR Deflicker
